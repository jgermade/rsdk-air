rsdk-air

One app for the RSDK engine decompilations and Sonic 3 A.I.R. Pick a game when it starts.

Your game files

No game data is included. Copy the files from games you own into the data folder:

GameFileFolder (inside the data folder)
Sonic the HedgehogData.rsdkgames/sonic1/
Sonic the Hedgehog 2Data.rsdkgames/sonic2/
Sonic CDData.rsdkgames/soniccd/
Sonic 3 A.I.R.Sonic_Knuckles_wSonic3.bin (4 MB)games/s3air/
Sonic ManiaData.rsdkgames/mania/

The data folder is:

Windows%APPDATA%\rsdk-air\
Linux~/.local/share/rsdk-air/
macOS~/Library/Application Support/rsdk-air/
Androidimporting files from the app is coming in a later release

Run rsdk-air --list to see which games were found, and why the others were not.
